Add `SolverFeatherPGS(deterministic=True)`, an opt-in mode for `articulated_contact_response="immediate"` that reserves constraint rows (contacts, joint limits, drives, mimic, loop closures, velocity limits and joint friction) in a fixed per-world order instead of through atomic counters, and sums split-mode right-hand sides in a fixed order. Given identical contact inputs in an identical order, repeated runs are bitwise identical on the same GPU model, driver and Warp build. `CollisionPipeline(deterministic=True)` supplies that order within its own limits: sort-key ties and the choice of contacts kept on a contact-buffer overflow can still vary. On row overflow, each world keeps its earliest rows in contact order and reports the rest as dropped. The mode allocates 16 bytes per contact-capacity slot for the per-step contact sort.
