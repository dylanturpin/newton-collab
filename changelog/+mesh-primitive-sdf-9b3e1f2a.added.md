Add `CollisionPipeline(mesh_primitive_sdf=True)` (and the same option on `NarrowPhase`), an experimental route for triangle-mesh vs analytic-primitive pairs (box, sphere, capsule, cylinder, cone) through the SDF contact kernels: the primitive's signed distance is evaluated in closed form along the mesh edges, and a new face pass emits the primitive's supporting points against each mesh face it pokes through, with the face normal and plane depth. This replaces the mesh-convex path that runs one GJK/MPR test per overlapping triangle. The primitive is neither converted to a mesh nor given an SDF; ellipsoid pairs keep the mesh-convex path because Newton's ellipsoid distance is a first-order approximation. Off by default. The analytic SDF dispatch shared with soft contacts now lives in `geometry/kernels.py` (`eval_analytic_sdf`, `eval_analytic_sdf_grad`, `eval_analytic_sdf_lower_bound`, `is_analytic_sdf_primitive`). The mesh-SDF pair buffers and the `NarrowPhase(max_mesh_mesh_pairs=...)` argument are renamed `shape_pairs_mesh_sdf`, `shape_pairs_mesh_sdf_count` and `max_mesh_sdf_pairs`.
