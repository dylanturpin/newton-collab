Add trajectory inverse kinematics: `newton.ik.IKSolverTrajectory` optimizes all frames of one or more joint trajectories jointly, reusing existing per-frame IK objectives (with one target per frame) and solving the block-banded Gauss-Newton system with either a batched block-tridiagonal Cholesky (`linear_solver="direct"`) or a block-Jacobi-preconditioned conjugate-gradient (`linear_solver="cg"`) backend. New temporal objectives couple consecutive frames: `IKObjectiveSmoothness` (finite-difference velocity/acceleration/jerk), `IKObjectiveVelocityLimit`, and `IKObjectiveJointReference`; `fixed_frames` anchors selected frames. See the `ik_trajectory` example.
