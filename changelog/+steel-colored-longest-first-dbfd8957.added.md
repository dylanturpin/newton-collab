Add `SolverSteel(propagation_color_order=...)` for `articulated_contact_response="propagation_colored"`. The default `"contact"` colors contact units in contact-index order as before. `"longest_first"` takes units with more rows first, so long units share colors, which shortens the colored sweep where one body carries many units of mixed length; on some stacked scenes it converges more slowly at a fixed iteration count.
