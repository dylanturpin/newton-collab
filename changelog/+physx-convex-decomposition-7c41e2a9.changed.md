Honor `PhysxConvexDecompositionCollisionAPI` on USD import. For prims that apply the API, `physxConvexDecompositionCollision:maxConvexHulls` (default 32) caps the total hull count of the imported mesh and `hullVertexLimit` (default 64) caps the vertices of each hull; CoACD runs with merging and decimation, splitting the hull budget across disconnected components. Assets that apply the API now import with fewer, simpler hulls. To keep the previous unconstrained decomposition, remove the API from the prim or call `ModelBuilder.approximate_meshes(method="coacd", merge=False)` on the shapes after import.
