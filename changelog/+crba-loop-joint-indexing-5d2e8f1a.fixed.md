Fix `SolverFeatherPGS` corrupting device memory and producing NaNs when a model contains loop joints or any articulation placed after one: the composite-inertia/CRBA chain indexed body-sized spatial workspaces by joint index, which only coincides with the child-body index in loop-free models. The chain now indexes through `joint_child`, and loop joints are excluded from the kinematic tree via a per-articulation tree-prefix bound.
