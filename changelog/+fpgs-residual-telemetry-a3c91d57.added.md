Add opt-in `debug_record_residuals` telemetry to `SolverFeatherPGS`: records every dense constraint row's pre-update residual `J.v + rhs` at each fused Gauss-Seidel visit into `SolverFeatherPGS.pgs_residual_log`, indexed `(world, global_iteration, row)` and zeroed at the start of every velocity solve. Requires `pgs_mode="matrix_free"`; matrix-free (body-pair) rows are not recorded. Disabled by default, with no buffer allocated and unchanged generated kernel source when off.
