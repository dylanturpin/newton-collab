Fix `SolverSteel` split mode failing to compile its tiled-row dense Gauss-Seidel kernel at large `articulation_constraint_max` (for example 256), where the packed Delassus triangle exceeds static shared memory. The default kernel selection now falls back to the scalar loop kernel when the estimated footprint plus a 2 KiB reserve exceeds 48 KiB (capacity 148 and above), and an explicit `tiled_row` kernel override over that budget raises `ValueError`.
