Speed up few-world `SolverSteel` scenes with `solve_mode="colored"`: when every world fits one block per SM and every articulation tree takes the one-warp tree kernels, the propagation PGS iteration loop runs as one launch with one block per world (latency mode), and colors wider than a warp are swept across the whole block. Results are bitwise identical to the per-pass launches, which still serve larger world counts.
