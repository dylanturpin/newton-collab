Run ``SolverFeatherPGS.notify_model_changed`` for ``JOINT_DOF_PROPERTIES`` (armature) and ``SHAPE_PROPERTIES`` (patch-friction geometry) on the device, so these notifications can be captured in a CUDA graph when sleeping is disabled. With joint friction enabled, an eager ``JOINT_DOF_PROPERTIES`` notification still validates ``joint_friction`` on the host; captured replays skip that check and use the coefficients as written.
