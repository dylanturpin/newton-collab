Run ``SolverFeatherPGS.notify_model_changed`` for ``JOINT_DOF_PROPERTIES`` (armature and joint-friction checks) and ``SHAPE_PROPERTIES`` (patch-friction geometry) on the device, so these notifications can be captured in a CUDA graph when sleeping is disabled. Invalid ``joint_friction`` builds no friction row and latches the solver world that owns the DOF (loop-closing joints included) in the new ``SolverFeatherPGS.joint_friction_invalid`` device array on every notify, including captured replays; an eager notify and the new ``SolverFeatherPGS.check_joint_friction`` raise ``ValueError`` for it.
