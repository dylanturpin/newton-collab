Shorten the per-row latency of the FeatherPGS matrix-free GS solve, which runs each world's dense rows as one serial chain. The final velocity-limit pass visits only the velocity-limit row segment; streamed row metadata is loaded with the next row's prefetched Jacobian; each torsion row issues its own loads before walking its members; and, while every world stays resident on the GPU, each launch sets up its friction pairs' 2x2 operators once and keeps a compact shared copy of row types and parents. Results are bitwise unchanged.
