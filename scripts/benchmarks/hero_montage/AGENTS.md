# Scene decoration rules

- Use curated, coherent decorations appropriate to each task. Automatic selection
  by scene class is allowed when it selects a deliberate decoration layout.
- Never add automatic table clutter: no random pens, clips, stationery clusters,
  tiny filler objects, or scattering props to make empty table edges look busy.
- A missing or empty `assets/task_decor.json` entry is not permission to invent
  filler. Keep only explicitly chosen task/class decorations.
- Preserve approved decoration layouts, their placement, and the mixed table
  palette. Do not replace them with obsolete builder defaults.
- Historical scripts and scene snapshots under `newton/tests/outputs` may contain
  retired clutter code. Preserve them for reproducibility, but never copy that
  behavior back into active builders or use it as a style reference.
- Follow `video_style_reference.py` for camera direction, lighting preservation,
  and editorial timing. These rules apply to local and remote render workflows.

- The wrecking crane uses stock gripper fingers to pinch the original rear
  counterweight. Do not restore the removed yellow handle or long jaw extensions.
