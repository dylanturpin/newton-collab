newton.solvers.feather_pgs
==========================

FeatherPGS solver module.

Use :class:`~newton.solvers.SolverFeatherPGS` as the canonical public solver class.

.. note::

   This page documents helper functions exposed through the ``newton.solvers.feather_pgs`` attribute.
   Because ``newton.solvers`` is a module rather than a package, use
   ``from newton.solvers import feather_pgs`` instead of ``import newton.solvers.feather_pgs``.
