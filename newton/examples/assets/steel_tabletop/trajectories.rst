Precomputed robot trajectories
=============================

``trajectories.json`` contains joint coordinates generated by the tabletop IK
planner for the six Steel demonstrations. Loading these paths avoids solving
the same waypoints and compiling specialized IK kernels on every first visit
to a scene.

Each entry is keyed by a SHA-256 digest of the robot's joint topology,
transforms, axes, initial coordinates, limits, driven and gripper coordinates,
end-effector offset, requested poses and waypoint spacing. Modified inputs
automatically fall back to runtime IK. Fallback CUDA solves reuse captured
graphs across waypoints.

Regenerate all paths from the repository root on a CUDA device::

    uv run --extra examples scripts/generate_steel_trajectories.py

Run the six Steel example outcome tests after regenerating the paths. Asset
downloads, mesh import and solver kernel compilation still occur as needed;
the precomputed trajectories remove the IK portion of scene initialization.
